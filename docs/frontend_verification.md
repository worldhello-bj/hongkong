# 前端实现与验收记录

## 已实现

TypeScript + Vite + MapLibre，使用打包依赖；官方 CSDI 楼层/单元几何与人工换乘拓扑分开展示。支持站点与楼层切换、起终点交换、三种步行偏好、香港时区、高铁截止时间、设施关闭情景、列车/巴士 ETA、来源面板和行程导出。无 WebGL 时以同源官方几何作 SVG 二维显示；未知位置不会伪造配准路径。

- TypeScript 检查和 Vite 生产构建通过；CI 同时执行前后端测试和构建。

## 实际浏览器验收：2026-10-09 UTC

经用户授权，使用临时静态预览，在云端 Chrome 的1170px宽视口实际操作并查看截图。

1. 最初发现站点标签重叠和 WebGL 失败导致空地图；修复后重新发布并复验。
2. 金钟官方楼层和室内单元显示成功，楼层按钮可切换；无 WebGL 时明确显示“二维软件渲染”。
3. 换乘拓扑的公交节点展开排列，主要月台与选定端点标注不再重叠；全部节点保留选择和完整提示。
4. 记录样例的起终点和21:00香港出发时间与表单一致，路线步骤、回放列车资料和来源时间可见。
5. 来源弹窗可打开并关闭，关闭后继续操作页面。
6. 官方金钟路网加载后显示1,300节点、1,396条线段的二维投影；静态预览中的重新计算按钮禁用并明确要求启动后端。

临时静态预览只审阅已记录数据及官方几何；不会冒充正在运行的 Python 实时规划服务。后端规划、约束和上游数据调用分别由 API 测试与来源观测验证。

## 尚未验证
